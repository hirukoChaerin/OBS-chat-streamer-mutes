Sonidos del chat

Toca uno para escucharlo. Así eliges el sonido de cada compañero.

Para asignarlo: npm run add-user -- --sound ana ding
O solo para un overlay: /overlay?user=ana&sound=ding

También puedes copiar un archivo propio a public/sounds/ (mp3, ogg o wav) y usar su nombre, por ejemplo ana.mp3.
